# 14 号 · 街头足球

抽卡站内的手机横屏单人 5v5。可用触屏、键盘和鼠标操作，比赛由浏览器本地模拟。网站用任意静态 HTTP 服务器启动后，从 `street-football/` 进入。桌面可加 `?touch=1` 预览触屏操作。

比赛和渲染代码改编自 [JosephUz/yakargol](https://github.com/JosephUz/yakargol/tree/5cef13b7cc0cfd9e278af719b6149e83369a82da)，保留 [MIT 许可](LICENSE)。本版使用自己的名称、界面、角色和球衣。`vendor/` 中为 Three.js 0.180.0 的两个浏览器模块及 [MIT 许可](vendor/LICENSE)。游戏内音效由 Web Audio 合成。
